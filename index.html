Como construir (Hibbeler)
  • Eixos: σ para a direita, τ positivo para baixo.
  • Centro C = (σméd; 0), σméd = (σx + σy)/2.
  • Ponto de referência A = (σx; τxy), que representa a face x.
  • Raio R = √[((σx − σy)/2)² + τxy²].
  • Girar o elemento θ no sentido anti-horário equivale a girar o raio CA de 2θ no mesmo sentido.
